**Cenário:** Fluxo de exceção do passo 2 (nenhuma matéria cadastrada)

**Preparação:**

a) Nenhuma matéria deverá estar cadastrada no sistema.

b) Nenhuma tarefa de estudo deverá estar cadastrada no sistema.

**Passos para execução do teste:**

1. Acessar a página inicial da aplicação Sistema Organizador de Estudos.
2. Selecionar o item "Tarefas".
3. Selecionar a operação "Nova".

**Resultado esperado:**

a) O sistema apresenta a mensagem:

> "É preciso cadastrar uma matéria antes de criar uma tarefa de estudo"

b) O sistema não apresenta o formulário de dados da tarefa e nenhuma tarefa é cadastrada.

c) Após o teste, o estado do sistema é o seguinte:

Matérias: nenhuma matéria cadastrada.

Tarefas de estudo: nenhuma tarefa cadastrada.

(X) Sucesso
